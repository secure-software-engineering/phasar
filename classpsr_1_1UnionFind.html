Detailed Description

template<SmallIdType IdT = uint32_t>
class psr::UnionFind< IdT >

Mutable union-find (disjoint-set) data structure over integer-like ids.

Supports join() (union by rank with path compression, via llvm::IntEqClasses) and find() (representative look-up). When all unions have been performed, call compress() to obtain a CompressedUnionFind that assigns dense sequential class indices.

Template Parameters
IdTElement type. Must satisfy SmallIdType (fits in uint32_t).
