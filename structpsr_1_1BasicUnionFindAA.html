Detailed Description

template<typename AnalysisDomainT, typename ObjectIdT = ValueId>
struct psr::BasicUnionFindAA< AnalysisDomainT, ObjectIdT >

Union-find alias-analysis that is neither context, nor field, nor indirection sensitive. Most useful for building a more precise alias-analysis on top of this, instead of using this directly.

Template Parameters
AnalysisDomainTThe analysis domain to use, e.g., LLVMPAGDomain.
ObjectIdTThe type of object-Ids (default ValueId).

Joins From and To unconditionally, ignoring the edge type. This is intentional: a flow-insensitive union-find without an indirection dimension must merge across Store/Load boundaries to stay sound. The resulting imprecision (pointers merged with pointees) is recovered when this analysis is intersected with IndirectionSensUnionFindAA via UnionFindAACombinator. Do not use BasicUnionFindAA standalone where pointer/pointee distinction matters.
