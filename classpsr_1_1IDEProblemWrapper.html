Detailed Description

template<IDEProblem ProblemTy>
class psr::IDEProblemWrapper< ProblemTy >

A simple wrapper over a pointer to an IFDS/IDE problem.

Useful for adding intermediate layers, e.g., IFDS->IDE translation, caching, etc.
