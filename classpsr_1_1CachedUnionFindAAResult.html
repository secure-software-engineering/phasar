Detailed Description

template<UnionFindAAResult AAResT, bool ShouldCacheMayAlias = true>
class psr::CachedUnionFindAAResult< AAResT, ShouldCacheMayAlias >

Lazy cache that wraps any UnionFindAAResult and memoises getRawAliasSet() results in a ValueIdMap.

Not thread-safe. Each unique ValueId is computed at most once on first access.

Template Parameters
ShouldCacheMayAliasWhen true (default), mayAlias() is answered via the cached alias sets (one set look-up). When false, mayAlias() is forwarded directly to the underlying result without materializing a set, which can be faster for analyses whose mayAlias() implementation is already O(1).
