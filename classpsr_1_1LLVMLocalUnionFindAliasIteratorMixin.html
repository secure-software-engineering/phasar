Detailed Description

template<typename Derived, typename AAResT>
class psr::LLVMLocalUnionFindAliasIteratorMixin< Derived, AAResT >

CRTP mixin adding a function-local view on top of a global UnionFindAAResult.

Extends LLVMUnionFindAliasIteratorMixin with forallAliasesOf() overloads that accept an llvm::Function* or llvm::Instruction* context. When a non-null context is provided, alias sets are intersected with the set of variables that are visible in that function (globals plus locals defined in that function), giving a function-local result even though the underlying analysis is interprocedural.
