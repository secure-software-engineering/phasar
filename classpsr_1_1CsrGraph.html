Detailed Description

template<IdType VtxId>
class psr::CsrGraph< VtxId >

Immutable directed graph in compressed-sparse-row format: the successors of vertex V are Targets[Offsets[V] .. Offsets[V+1]).

Build it with fromEdges() or assignEdges(). assignEdges() reuses the allocated storage, so a single CsrGraph object can serve as buffer for many short-lived graphs.
