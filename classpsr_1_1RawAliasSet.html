Detailed Description

template<SmallIdType IdT>
class psr::RawAliasSet< IdT >

Sparse bit-set used to represent alias sets in union-find analyses.

Currently backed by llvm::SparseBitVector for compact storage when ids are scattered in a large range and dense storage when ids are clustered. Satisfies IsRawAliasSet.

Template Parameters
IdTInteger-like id type (e.g., ValueId).
