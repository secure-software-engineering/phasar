Detailed Description

Opt-in call-string context-sensitivity for AndersenOTFSolver.

The call-string k-limit is fixed at 1: a selected function gets one set of PAG nodes per call-site that reaches it. Non-selected functions keep a single set of nodes shared by all callers, exactly as before.

◆ MaxContextsPerFunction

unsigned psr::ContextSensitivityOptions::MaxContextsPerFunction = 32

Cap on distinct calling contexts per function; further call sites fall back to the shared root context. A selected function costs one clone of its whole body per context, so without this a single hot function can consume MaxContextualNodes on its own.

unsigned psr::ContextSensitivityOptions::MaxContextualFunctionSize = 256

Mode::Dynamic only: functions with more LLVM instructions than this are never selected. Cloning a large body per context is expensive, and large functions are rarely the point where callers merge.

◆ MaxContextualNodes

size_t psr::ContextSensitivityOptions::MaxContextualNodes = 20'000

Hard cap on context-qualified PAG nodes. Once reached, no function is newly selected and no already-selected function gets a further context: sound, just less precise. This is the knob that bounds run time; solve time grows super-linearly in the node count, so raising it is not a proportional trade.

unsigned psr::ContextSensitivityOptions::MaxLocalMergeFunctionSize = 0
