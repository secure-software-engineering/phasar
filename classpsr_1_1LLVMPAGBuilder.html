Detailed Description

Concrete PAGBuilder for LLVM IR.

Traverses all functions in the given LLVMProjectIRDB and emits PAG nodes and edges to the provided PBStrategyRef.

Achieves basic field sensitivity by handlking constant GEPs in an ad-hoc manner.

An optional LLVMFunctionDataFlowFacts object can be supplied to apply pre-computed library summaries at potentially declaration-only calls.
