Detailed Description

template<typename AnalysisDomainT, unsigned K = 5>
class psr::IndirectionSensUnionFindAA< AnalysisDomainT, K >

Union-find alias-analysis that achieves (partial) indirection-depth-context sensitivity through heap cloning. Use this with pag::PBMixin to implement pag::PBStrategy.

Template Parameters
AnalysisDomainTThe analysis domain to use, e.g., LLVMPAGDomain.
KThe maximum depth of pointer-indirections that can be differentiated (default 5).
