Detailed Description

template<typename N, unsigned K = 1>
struct psr::CallingContext< N, K >

A K-limited call-string context. Stores the K most recent call-sites that led to the current execution point (index 0 = most recent). The default K = 1 gives a 1-call-site context (CFA/k-CFA style).
