Detailed Description

template<typename Derived, typename AAResT>
requires RawAAResult<std::remove_cvref_t<AAResT>>
struct psr::LLVMRawAliasIteratorMixin< Derived, AAResT >

CRTP mixin that adds the LLVM alias-iterator interface to a class that holds a RawAAResult and a ValueCompressor<PAGVariable>.

Provides forallAliasesOf(), mayAlias(), and alias() overloads accepting both llvm::Value* and ValueId arguments. Results are reported as llvm::Value* via the stored ValueCompressor.

The derived class must expose a VC member (pointer to a ValueCompressor<PAGVariable>).
