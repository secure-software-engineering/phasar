Detailed Description

template<typename AnalysisDomainT, unsigned K = 1>
class psr::CallingContextSensUnionFindAA< AnalysisDomainT, K >

Union-find alias-analysis that achieves (partial) calling-context sensitivity through heap cloning. Implements pag::PBStrategy.

Template Parameters
AnalysisDomainTThe analysis domain to use, e.g., LLVMPAGDomain.
KThe maximum length of call-strings (default 1).
