Detailed Description

Concrete IsAliasInfo implementation backed by a union-find alias analysis.

Constructed once from an LLVMProjectIRDB and a call graph; the chosen analysis variant is determined by Config. Alias sets are materialized lazily on first query and cached per ValueId in AliasSets.

Note
When AnalysisLocality::FunctionLocal is selected, alias sets are filtered to variables visible in the function that contains the query instruction. The per-ValueId cache does not account for the instruction context, so the first caller's function wins — do not mix queries to local pointers from different functions for the same value in local mode.
