Detailed Description

template<typename T>
class psr::ValueCompressor< T >

A utility-class that assigns sequential integer-like ids (psr::ValueId) to every inserted value.

In contrast to psr::Compressor, the ValueCompressor can optionally assign the same id to multiple values, and it can even produce ids without corresponding values.

Template Parameters
TThe type of inserted values. Expected to be mostly small and trivial.
