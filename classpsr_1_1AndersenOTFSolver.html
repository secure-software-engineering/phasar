Detailed Description

Andersen-style inclusion-based points-to analysis that co-refines the call graph and points-to sets in a single fixpoint.

Unlike the staged pipeline (resolver → PA), this solver owns its own function-worklist loop: direct calls add callees immediately; indirect calls are resolved as pts(fp) grows.

Phase 1: context- and field-insensitive.
