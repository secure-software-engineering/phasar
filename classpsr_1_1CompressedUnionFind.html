Detailed Description

template<SmallIdType IdT, SmallIdType MappedIdT>
class psr::CompressedUnionFind< IdT, MappedIdT >

Read-only view of a compressed union-find: maps each original element to a dense sequential class index in the range [0, numClasses()).

Obtained by calling UnionFind::compress<MappedIdT>(); not directly constructible.

Template Parameters

MappedIdTType for the dense class indices.
